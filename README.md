# Apoorva Srinivasan — Portfolio

Static portfolio built with Vite and deployed to GitHub Pages.

## Local development

Requires Node.js 20 or later. The included `.nvmrc` selects Node.js 24 when using `nvm`.

```sh
npm ci
npm run dev
```

## Deploy to GitHub Pages

The `Deploy portfolio to GitHub Pages` workflow builds and deploys the site on every push to `main` (and can be run manually from the Actions tab).

In the repository settings, open **Pages** and set **Build and deployment → Source** to **GitHub Actions**. The project site will be served at:

`https://apoorva5544.github.io/portfolio/`
